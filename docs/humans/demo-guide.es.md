# Probar una selección

[English](demo-guide.md) · Español

Con Node.js 22.18 o superior instalado, abre una terminal en la carpeta de Furrify. Ejecuta `npm ci` la primera vez y después `npm run dev`. Abre la dirección local indicada en la terminal. Para cerrar, pulsa Ctrl+C.

1. En «Código de solicitud», escribe **FUR-101** y pulsa «Ver recomendaciones». Aparece brevemente la búsqueda y después verás Taller Bruma y Atelier Musgo, cada uno con el motivo de su selección.
2. Prueba **FUR-000**. La página indica que aún no hay recomendaciones.
3. Prueba **FUR-503**. La consulta muestra un problema y te permite volver a escribir. Con **FUR-101** volverás a obtener la selección.
4. Escribe **hola**. La página explica el formato esperado.

Los códigos son de ejemplo. La página no crea solicitudes ni guarda lo escrito al recargar. El error de FUR-503 está preparado para repetirse siempre. [Qué incluye el piloto](overview.es.md).
