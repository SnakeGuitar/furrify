# Furrify

English · [Español](README.es.md)

Furrify helps adult buyers find independent fursuit and accessory makers. In this local prototype, you can look up a fictional shortlist and see why each workshop was chosen.

With Node.js 22.18 or later, run `npm ci` and then `npm run dev`. Open the local address printed by Vite and enter `FUR-101`.
