# Furrify

[English](README.md) · Español

Prototipo local de consulta de talleres independientes para compradores adultos. La selección que se muestra es manual y ficticia.

Con Node.js 22.18 o superior, ejecuta `npm ci` y `npm run dev`. Abre la dirección local que indica Vite y prueba `FUR-101`.
